## Description
An automatic vehicle's headlight control system that automatically switches ON/OFF headlights based on surrounding light intensity using an LDR sensor and relay circuit.

## Components Used
- LDR Sensor
- Relay Module
- DC-DC Buck Converter
- 12V Lithium-Ion Battery
- Activa Headlight
- Connecting Wires

## Working Principle
1. LDR sensor detects surrounding light intensity
2. In darkness, relay activates automatically
3. Vehicle headlight turns ON
4. In bright light, relay turns OFF
5. Headlight switches OFF automatically

## Features
- Automatic headlight switching
- Low power consumption
- Simple circuit design
- Cost-effective system
- Improves driving safety

## Applications
- Two-wheelers
- Automatic vehicle lighting
- Smart lighting systems

## Future Scope
